# 🥘 NutriAi — AI-Powered Meal Analyzer

NutriAi is a Streamlit web application that uses **Google Gemini Vision** to analyze meal photos, calculate nutrition, generate personalized 7-day meal plans, and chat with an AI nutritionist — all tailored to your personal health goals.

---

## ✨ Features

- 📸 **Meal Analysis** — Upload a food photo; Gemini identifies items and calculates calories, macros, and gives goal-specific feedback
- 📋 **7-Day Meal Planner** — Personalized meal plan based on your TDEE, goal, and food preferences (downloadable)
- 🗣️ **AI Nutritionist Chat** — Ask any nutrition question; responses are personalized to your profile
- 📊 **Health Stats** — BMI and TDEE displayed in the sidebar
- 🔐 **Secure Auth** — Passwords hashed with bcrypt; secrets stored in `.env`
- 💾 **Persistent History** — Meal history, diet plans, and chat saved to Supabase

---

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| UI | Streamlit |

## ⚙️ Setup

### 1. Clone the repo
```bash
git clone https://github.com/BadrinathGouru/NutriAi.git
cd NutriAi
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Configure environment variables
```bash
cp .env.example .env
```
Edit `.env` and fill in your keys:
```env
GOOGLE_API_KEY="your_gemini_api_key"      # https://aistudio.google.com/apikey
SUPABASE_URL="https://xxxx.supabase.co"   # Supabase Project Settings → API
SUPABASE_KEY="eyJhbGci..."                # Supabase anon/public JWT key
GEMINI_MODEL="gemini-1.5-flash"           # Optional: override the default model
```

### 4. Create Supabase tables

Go to your Supabase project → **SQL Editor** → **New Query** → paste and run:

```sql
-- Users table
CREATE TABLE IF NOT EXISTS users (
    id              BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name            TEXT NOT NULL,
    username        TEXT UNIQUE NOT NULL,
    password        TEXT NOT NULL,       -- bcrypt hash, never plain text
    age             INT,
    gender          TEXT,
    height_cm       NUMERIC,
    weight_kg       NUMERIC,
    goal            TEXT,
    activity_level  NUMERIC,
    tdee            NUMERIC
);

-- Meal history table
CREATE TABLE IF NOT EXISTS meal_history (
    id            BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    user_id       BIGINT,
    timestamp     TEXT,
    image_url     TEXT,
    summary       TEXT,
    meal_consumed TEXT,
    calories      TEXT
);

-- Diet plans table
CREATE TABLE IF NOT EXISTS diet_plans (
    id        BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    user_id   BIGINT,
    plan      TEXT,
    timestamp TEXT
);

-- Chat history table
CREATE TABLE IF NOT EXISTS chat_history (
    id        BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    user_id   BIGINT,
    role      TEXT,       -- 'user' or 'assistant'
    content   TEXT,
    timestamp TEXT
);

-- Disable RLS for all tables (simple dev setup)
ALTER TABLE users        DISABLE ROW LEVEL SECURITY;
ALTER TABLE meal_history DISABLE ROW LEVEL SECURITY;
ALTER TABLE diet_plans   DISABLE ROW LEVEL SECURITY;
ALTER TABLE chat_history DISABLE ROW LEVEL SECURITY;
```

### 5. Create Supabase Storage bucket

In Supabase → **Storage** → **New bucket** → name it `meal-images` → enable **Public bucket**.

### 6. Run the app
```bash
python -m streamlit run app2.py
```

Open **http://localhost:8501** in your browser.
